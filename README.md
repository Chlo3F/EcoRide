# EcoRide

**EcoRide** est une plateforme web de covoiturage écologique dont l’objectif principal est d’optimiser les trajets tout en réduisant l’empreinte carbone des déplacements. Ce projet vise à proposer une solution alternative, pratique et responsable pour les trajets quotidiens ou occasionnels.

## 🌱 Fonctionnalités principales

- Création et gestion de trajets pour conducteurs  
- Réservation de trajets pour passagers  
- Page de profil avec informations utilisateurs  
- Tableau de bord personnalisé  
- Système de filtrage et recherche de trajets  
- Intégration de bases de données relationnelles et NoSQL  

## 🛠️ Technologies utilisées

### Environnement de développement

- Visual Studio Code avec les extensions :  
  WSL, Twig Pack, PHP Intelephense, PHP Debug, Docker, HTML CSS Support, IntelliSense

### Front-end

- HTML5, CSS3  
- Bootstrap 5  
- JavaScript  

### Back-end

- PHP 8.2  
- Symfony 7.2  

### Base de données

- MariaDB 10.6 (relationnelle)  
- MongoDB 6.0 (NoSQL)  
- Adminer (interface pour MariaDB)  
- MongoDB Compass (interface pour MongoDB)  

### Autres

- Docker Desktop  
- Docker Compose  
- Twig (moteur de templates)  

## ⚙️ Prérequis

- PHP 8.2  
- Composer  
- Docker & Docker Compose  
- Node.js (facultatif selon les besoins front-end)  
- Accès à MariaDB & MongoDB (via Docker ou local)
